# Radian Dial Engine — Phase 6 Implementation Report: Widget Frame Strip (L)

**Date:** 30 September 2026  
**Status:** Completed & Verified  
**Invariants Addressed:** I8 (One input → one DialModel → identical result on every surface), RC5 (Stale widget image), RC6 (Sync input drift across entry points), RC10 (Eliminated 60-second headless Flutter re-rendering & torn reads).

---

## 1. Executive Summary

Phase 6 replaces the expensive, battery-draining per-minute headless Flutter re-render and triple-file-copy pipeline with the **Widget Frame Strip** architecture:
- **Precomputed Dial Frames:** The Flutter engine precomputes 720×720 PNG dial face backgrounds (both light and dark mode variants) and writes a `frames.json` manifest covering a 36-hour planning horizon.
- **Native Android Needle Warping:** Native Kotlin components (`NeedleInterpolator`, `WidgetFrameStore`, `SectographWidgetProvider`) cache the strip, load the static face matching the system UI night mode, and rotate the needle with sub-minute precision at 60fps/minute using the exact piecewise-linear warp table generated by `WarpSolver`.
- **Unified Sync Pipeline:** Scattered and redundant `ref.listen` subscriptions in `HomeScreen` and `DialSystemIntegrationsSection` are replaced with a single Riverpod `WidgetSyncCoordinator` with an 800ms debounce interval.
- **Cross-Platform Verification:** Test vectors (`test/fixtures/warp_interpolation_vectors.json`) run against both Dart (`test/engine/warp_vectors_test.dart`) and Kotlin (`NeedleInterpolatorTest.kt`), guaranteeing identical angle transformations across Dart and Android.

## 2. Changes Made & Files Touched

### A. Core Engine & Frame Planning (`lib/engine/`, `lib/domain/`)
1. **`lib/engine/widget_frame_planner.dart`**:
   - Plans 12h/24h dial windows across a 36-hour horizon.
   - Computes layout signatures for static face deduplication.
   - Serializes frame intervals, piecewise-linear warp tables, center event info, and data versions to JSON.
2. **`lib/engine/dial_model.dart` & `dial_model_builder.dart`**:
   - Added `computeLayoutSignature` to hash static visual elements excluding the needle angle.
3. **`lib/domain/schedule/occurrence_adapter.dart`**:
   - Added `projectOccurrencesForHorizon` projecting occurrences across the 36-hour planning window using `ZoneDayProjector`.

### B. Flutter Widget Services & Coordination (`lib/core/`, `lib/presentation/`)
4. **`lib/core/services/widget_frame_service.dart`**:
   - Implements atomic staging, rendering 720×720 PNGs (light & dark) matching the user seed color, writing `frames.json`, and updating `current.json`.
   - Supports `baseDirOverride` for hermetic testing.
5. **`lib/presentation/controllers/widget_sync_coordinator.dart`**:
   - Unified Riverpod `StateNotifier` listening to `allEventsProvider`, `dialSettingsProvider`, and `zoneClockProvider`.
   - 800ms debounce timer, `mounted` guards against disposal race conditions, and `syncNow({ThemeData? theme})`.
6. **`lib/entrypoints/widget_refresh_entrypoint.dart`**:
   - `@pragma('vm:entry-point') Future<void> widgetRefreshMain()` for headless background WorkManager executions.
7. **`lib/presentation/screens/home_screen.dart`**:
   - Removed 5 fragmented `ref.listen` calls; wired lifecycle and sync to `ref.watch(widgetSyncCoordinatorProvider)`.
8. **`lib/presentation/widgets/editor/components/dial_system_integrations_section.dart`**:
   - Routed manual "Sync Widget" button through `widgetSyncCoordinatorProvider.notifier.syncNow()`.
9. **`lib/core/dial_engine_flags.dart`**:
   - Enabled `widgetFrameStrip = true`.

### C. Android Native Kotlin Layer (`android/`)
10. **`android/app/src/main/kotlin/com/ksmxtech/sectograph_mcp/NeedleInterpolator.kt`**:
    - Pure Kotlin monotonic piecewise-linear warp table interpolator mirroring `WarpMap.forward`.
11. **`android/app/src/main/kotlin/com/ksmxtech/sectograph_mcp/WidgetFrameStore.kt`**:
    - High-performance disk cache reading `current.json` and `frames.json`.
    - Selects light/dark PNG variants based on `UI_MODE_NIGHT`.
    - Evaluates freshness (`isStale = nowMs > plan.validUntilMs`).
12. **`android/app/src/main/kotlin/com/ksmxtech/sectograph_mcp/SectographWidgetProvider.kt`**:
    - Loads active frame, rotates needle via `NeedleInterpolator`, displays center title, and paints an amber freshness dot on the bezel if stale.
    - Schedules minute alarms or frame transition wakeups (whichever occurs first).
13. **`android/app/src/main/kotlin/com/ksmxtech/sectograph_mcp/MainActivity.kt`**:
    - Implemented `'updateFrameStrip'` method call handler on `com.ksmxtech.sectograph_mcp/widget`.
14. **`android/app/build.gradle.kts`**:
    - Added `testImplementation("org.json:json:20240303")` for JUnit test vector parsing.

### D. Cross-Platform Test Suites (`test/`)
15. **`test/fixtures/warp_interpolation_vectors.json`**:
    - Shared test vectors with identity, standard, compressed, and expanded edge cases.

17. **`android/app/src/test/kotlin/com/ksmxtech/sectograph_mcp/NeedleInterpolatorTest.kt`**:
